# DataTalk-AI
Ask Question about your dataset


- Built a Streamlit app that lets users upload CSV files and explore their data by asking questions in plain English.

- Connected the Ollama `llama3.2` model to generate pandas code based on the uploaded data’s columns and sample rows.

- Used Pandas to load CSV data, preview rows, and display answers in the app.

- Added basic error handling to show when generated code cannot run.
